# job-app-automation

Making a script to automate populating excel sheet with the jobs I've applied to. 

Directory contains the excel file, Applications.xlsx and the script, as well as a simulator for a GitHub contribution graph for the frequency at which you apply. Check out your most recently used 

### Instructions to use: 
In your CLI navigate to the folder your excel sheet is stored. 
Run "python apps_automation.py".
Follow the prompts. 


### Instructions to make the contribution tree
In your CLI navigate to the folder your excel sheet is stored. 
Run "python github_graph_generator.py".
matplotlib should generate the graph.
